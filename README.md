# ARM Template for DotnetCore Linux Labs

> **The purpose of this repository is intended just for troubleshooting training material and it is not recommended to take this as a reference for production scenarios**.

## Runtime

Both templates use .NET 10.0. The corresponding [lab 1](https://github.com/azureossd/dotnetcore-linux-1) and [lab 2](https://github.com/azureossd/dotnetcore-linux-2) source projects must target `net10.0` before deploying these templates. Updating the App Service runtime alone does not retarget an existing application.
